# Личный Telegram-бот v0.1

Приватный бот только для владельца (чужие пользователи игнорируются).

**Функции:** 🔐 менеджер паролей · 📝 заметки · 👤 контакты

## 1. Подготовка
1. В Telegram открой **@BotFather** → `/newbot` → получи **токен**.
2. Узнай свой числовой ID у **@userinfobot**.

## 2. GitHub
```bash
git init && git add . && git commit -m "v0.1"
git branch -M main
git remote add origin https://github.com/<ты>/<репозиторий>.git
git push -u origin main
```
Репозиторий лучше сделать **Private**. Файлы `.env` и `data/` в git не попадают (см. `.gitignore`).

## 3. Termux
```bash
pkg update && pkg upgrade
pkg install python git python-cryptography
git clone https://github.com/<ты>/<репозиторий>.git
cd <репозиторий>
pip install -r requirements.txt
cp .env.example .env && nano .env     # впиши BOT_TOKEN и OWNER_ID
chmod +x run.sh && ./run.sh
```
Для приватного репозитория при `git clone` понадобится токен GitHub (PAT) в качестве пароля.

Обновление: `git pull`, затем перезапуск `./run.sh`.
Чтобы бот жил при закрытом Termux: `pkg install tmux`, запускай `./run.sh` внутри `tmux`.

## Как это работает
- **Пароли:** мастер-пароль → ключ (scrypt) → шифрование Fernet. Логины и пароли лежат в базе зашифрованными, мастер-пароль нигде не хранится (**забыл — не восстановить**). Авто-блокировка через 5 минут, пауза после 5 неверных попыток. Сообщения с секретами удаляются из чата (твой ввод — сразу, ответ бота — через 30 с).
- **Заметки и контакты:** хранятся в SQLite **без шифрования** (`data/bot.db`).
- Команды: `/menu`, `/lock`, `/cancel`.

## Важно про безопасность
Чаты с ботами в Telegram **не имеют сквозного шифрования**: пароли проходят через серверы Telegram, даже если сообщение удалено. Для критичных паролей (банк, почта) лучше специализированный менеджер.

## Бэкап
Копируй `data/bot.db` (пароли внутри зашифрованы).
